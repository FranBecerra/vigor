# JM Press and Kaz Press: initial catalogue record

Reviewed 2026-09-30. These were already imported from guide pages 210 and 211. Their existing `guide-210` / `guide-211` identifiers are preserved; no duplicate entries are added. Complete source text and rendered figures were inspected. They are manually selectable, now explicitly unscored rather than retaining an unjustified generic rubric, and are not promoted automatic hypertrophy winners. No quantitative head-to-head hypertrophy or recovery evidence was identified in the searches performed; absence in this search is not proof that no study exists.

Naming is not universally standardized: Kaz Press is retained as the athlete-facing name of the guided-bar variant, with Smith JM Press in the same name rather than creating another alias entry with identical equipment.

Technique provenance: the user's source guide pages 210–211 show the Smith versus free-bar implements and explicitly distinguish the elbow-focused hybrid from a close-grip bench press. The guide's assertion of superior triceps stimulus is treated as a coaching judgement, not direct comparative hypertrophy evidence. [JM Blakley's supplemental-work explanation](https://elitefts.com/blogs/training/listen-table-talk-podcast-clip-how-jm-blakley-chooses-his-supplemental-bench-movements-2) supports its accessory context; [Sergio M. Coach's Kaz/Smith JM demonstration](https://www.youtube.com/watch?v=ksecDmyNvWM) identifies the guided-bar variant. These coaching sources support identification/context, not comparative hypertrophy, tendon treatment or pain-prevention claims.

The scoring API continues to reject requests for an unscored stimulus rating. Sequencing calculations use the upper ordinal planning bound when a manual unscored exercise is present in previous work; this is explicitly a conservative uncertainty fallback, not a stored or displayed fatigue score. Duration and manual prescriptions use the accessory profile, without converting a bench e1RM into a JM/Kaz load. Schema, search, manual prescription and automatic-exclusion behavior require tests.
