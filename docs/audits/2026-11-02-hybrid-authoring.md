# Joint hybrid authoring — 2026-11-02

## Scope

New hybrid creation starts without an existing routine. The full strength/hypertrophy generator returns an accepted prescription in memory; it does not save or activate independently. The cardio authoring step keeps that roster mandatory. A final joint review checks combined estimated minutes, a shared per-session ceiling, relative-day availability, active days/doubles and omitted cardio. No silent trimming of either dose. Shared settings and the cardio draft survive local back/edit navigation. An unchanged accepted strength draft retains its identity; changing its source requires renewed cardio review.

Priority and strength adaptation goal are separate. This increment recommends same-day order, not priority-based dose redistribution. It does not deliver quality sessions, a single four-goal entry, integrated activation, calendar-aware sport capacity over the whole horizon, elapsed-hour spacing, cross-launch draft persistence, session drag/drop or sensors. Saved strength remains inactive, with an explicit action to return to Training and activate it before activating the linked cardio. Existing active plans are never replaced.
